# Track — سامانه ردیاب هدف

پروژه‌ای دانشجویی در حوزه GIS برای استخراج موقعیت سه‌بعدی یک شیء متحرک با استفاده از مشاهدات چند ناظر ثابت.

## ویژگی‌ها

- ثبت ناظرها با مختصات WGS84 (ورودی DD یا DMS) و ارتفاع از DEM
- ثبت دستی مشاهدات (زاویه سمت + زاویه ارتفاعی)
- محاسبه تقاطع ژئودزیک خطوط دید با Weighted Least Squares
- استخراج موقعیت سه‌بعدی هدف + دایره خطا
- نمایش هدف و مسیر حرکت روی نقشه با لایه‌لایه شدن
- خروجی گزارش Excel و PDF
- ذخیره/بارگذاری/بکاپ پروژه در SQLite
- تحویل به‌صورت EXE تک‌کلیکی ویندوز، کاملاً آفلاین

## پشته فنی

| بخش | فناوری |
|---|---|
| زبان | Python 3.11+ |
| رابط کاربری | PyQt6 / PySide6 |
| نمایش نقشه | QGraphicsView سفارشی |
| خواندن GeoTIFF / DEM | GDAL + rasterio |
| محاسبات ژئودزیک | pyproj + geographiclib |
| Least Squares | numpy + scipy |
| دیتابیس | SQLite + SpatiaLite |
| بسته‌بندی | PyInstaller → EXE |
