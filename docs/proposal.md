# پروپوزال نهایی: سامانه ردیاب هدف (Target Tracker)

## ۱. معرفی

پروژه‌ای دانشجویی در حوزه GIS برای استخراج موقعیت سه‌بعدی یک شیء متحرک با استفاده از مشاهدات چند ناظر ثابت. هر ناظر شیء را در یک **زاویه سمت (Azimuth)** و یک **زاویه ارتفاعی (Elevation)** نسبت به افق می‌بیند. با ترکیب مشاهدات چند ناظر و به‌کارگیری **Weighted Least Squares** روی بیضوی WGS84، موقعیت بهینه شیء به‌همراه **دایره خطای تخمین** محاسبه و روی نقشه نمایش داده می‌شود.

برنامه یک اپلیکیشن **دسکتاپ ویندوزی** با رابط کاربری **فارسی (RTL)** و **تم Dark** است، کاملاً **آفلاین**، بدون نیاز به نصب QGIS یا هر نرم‌افزار جانبی. تحویل نهایی: یک فایل **EXE تک‌کلیکی** با نام **«ردیاب»**.

---

## ۲. محدوده و اهداف

- ثبت ناظرها با مختصات WGS84 (ورودی DD یا DMS) و ارتفاع از DEM.
- ثبت دستی مشاهدات (زاویه سمت + زاویه ارتفاعی) برای هر ناظر.
- محاسبه تقاطع ژئودزیک خطوط دید با Weighted Least Squares.
- استخراج موقعیت سه‌بعدی هدف + دایره خطا.
- نمایش هدف و مسیر حرکت روی نقشه با قابلیت لایه‌لایه شدن.
- خروجی گزارش Excel و PDF.
- ذخیره/بارگذاری/بکاپ پروژه در SQLite.
- تحویل به‌صورت EXE قابل اجرا روی ویندوز، بدون نیاز به نصب چیز دیگری.

---

## ۳. سیستم مختصات (CRS)

| مورد | مقدار |
|---|---|
| ذخیره‌سازی داده | WGS84 (EPSG:4326) |
| محاسبه و نمایش | Lambert Conformal Conic سفارشی ایران |
| گزینه ثانویه | UTM Zone 39N (EPSG:32639) — فقط در Settings |

**پارامترهای Lambert سفارشی ایران:**

```
Projection          : Lambert Conformal Conic
False_Easting       : 0
False_Northing      : 0
Central_Meridian    : 54
Standard_Parallel_1 : 30
Standard_Parallel_2 : 36
Latitude_Of_Origin  : 24
Linear Unit         : Meter
Datum               : WGS84
```

**نکته:** ارتفاع‌ها ژئوئیدی (MSL) هستند و اختلاف با بیضوی (حدود ۲۵ متر در ایران) لحاظ نمی‌شود. این نکته صریحاً در مستندات فنی ذکر می‌شود.

## ۴. مدل داده (SQLite + SpatiaLite)

یک فایل SQLite واحد برای همه پروژه‌ها. اگر حجم فایل از ۵۰۰ مگابایت گذشت، هشدار داده شود.

### projects
`id, title, crs_project, crs_storage, default_max_range_m, default_angle_accuracy_deg, active_target_id, created_at`

### observers
`id, project_id, name, x_wgs84, y_wgs84, elevation_m, range_override_m, color, shape, font_size, is_active_in_calc, created_at`

### targets
`id, project_id, name, color, created_at`

### observations
`id, project_id, target_id, observer_id, azimuth_deg, elevation_deg, angle_accuracy_deg (nullable), timestamp_utc, is_active`

### tracks
`id, target_id, computed_x, computed_y, computed_z, error_radius_h_m, error_vertical_m, timestamp_utc, status`

مقادیر status: `valid / low_accuracy / ambiguous / single_observer`

### settings
`id, project_id, default_angle_accuracy, warn_angle_threshold_deg (۵), critical_angle_threshold_deg (۲), interpolation_enabled, interpolation_method (linear / catmull-rom), track_visible, max_range_m (۱۰۰۰۰۰), observer_color, target_color, track_color, font_name (Vazir), font_size (۱۴), log_level, coordinate_format (DD / DMS)`

## ۵. جریان کاربری

1. کاربر پروژه جدید می‌سازد.
2. یک یا چند نقشه ژئورفرنس (GeoTIFF / تصویر Georeferenced) بارگذاری می‌کند و یکی را Basemap می‌کند. لایه‌ها قابل روشن/خاموش، شفافیت و جابه‌جایی ترتیب هستند. لایه رویی نمایش داده می‌شود.
3. DEM را بارگذاری می‌کند. ارتفاع ناظرها خودکار از DEM خوانده می‌شود (Bilinear؛ در NoData → Nearest؛ بدون DEM → هشدار و ارتفاع ۰ قابل ویرایش).
4. ناظرها را با نام، x، y (DD یا DMS)، برد اختیاری، ارتفاع قابل ویرایش اضافه می‌کند.
5. ناظرها روی نقشه با مثلث آبی پررنگ + نام نمایش داده می‌شوند (قابل تنظیم رنگ/شکل/فونت).
6. کاربر هدف فعال را در dropdown پنل کناری انتخاب می‌کند یا «هدف جدید» می‌زند.
7. کلیک روی ناظر → پاپ‌آپ با دو فیلد زاویه سمت + ارتفاعی + فیلد اختیاری دقت زاویه (فقط برای سمت).
8. تأیید → timestamp UTC ثبت، خط دید تا برد ناظر (یا ۱۰۰ کیلومتر پیش‌فرض) رسم می‌شود.
9. وقتی ناظر دوم همان هدف فعال را می‌بیند و ثبت می‌کند:
   - **اگر تقاطع معتبر بود:** خطوط موقت حذف، نقطه هدف قرمز با هاله پالسی + دایره خطا نمایش داده می‌شود.
   - **اگر تقاطع نبود یا زاویه بین خطوط < آستانه:** هشدار «دقت پایین» یا «احتمال شیء متفاوت»، خطوط امتداد می‌یابند، نقطه `low_accuracy` یا `ambiguous` علامت می‌خورد.
   - **اگر ناظر دیگر مشاهده قدیمی داشت:** هشدار «ناظر X آپدیت نشده — آیا از مشاهده قدیمی استفاده شود؟» + گزینه غیرفعال کردن آن ناظر در محاسبه.
10. کاربر می‌تواند ناظر را **آپدیت کند** → مشاهده قبلی `is_active=false` و یک نقطه track جدید ساخته می‌شود.
11. کاربر می‌تواند مشاهده را **ویرایش یا حذف** کند → نقطه track بازمحاسبه/حذف می‌شود.
12. مسیر حرکت با چک‌باکس نمایش داده می‌شود. **هر هدف مسیر مستقل خودش** دارد؛ بین اهداف مختلف خطی کشیده نمی‌شود.
13. خروجی Excel و PDF.
14. ذخیره/بارگذاری/بکاپ پروژه به‌صورت ZIP (SQLite + JSON تنظیمات + لاگ — بدون نقشه‌ها).

---

## ۶. الگوریتم محاسبه

1. تبدیل مختصات ناظرها از WGS84 به Lambert سفارشی (pyproj).
2. ساخت بردار خط دید هر ناظر در فضای سه‌بعدی (شمال = ۰، ساعتگرد؛ ارتفاع مثبت به بالا، منفی به پایین).
3. حل **Weighted Least Squares** برای یافتن نقطه‌ای با کمترین مجموع مربع فاصله تا همه خطوط:
   - وزن هر خط: `w_i = 1 / σ_i²`
   - `σ_i = angle_accuracy_i`؛ اگر وارد نشده → وزن پیش‌فرض بدون دایره خطا.
4. **تعریف «تقاطع» = نقطه بهینه Least Squares**، نه تلاقی هندسی دقیق.
5. شعاع خطای افقی: `σ_offset_i = d_i × sin(σ_angle_i)` (تقریب مرتبه اول، خطا < ۱٪ برای دقت < ۱۰ درجه). شعاع دایره = بیشترین مقدار.
6. خطای عمودی جدا محاسبه، فقط در پنل اطلاعات نمایش داده می‌شود.
7. **اعتبارسنجی هندسی:**
   - زاویه بین دو خط < ۵ درجه → `low_accuracy`
   - زاویه بین دو خط < ۲ درجه → `ambiguous`
8. تبدیل نقطه بهینه از Lambert به WGS84 برای ذخیره.
9. ارتفاع هدف از تقاطع سه‌بعدی با ارتفاع ناظر (DEM) و زاویه ارتفاعی.
10. **درون‌یابی مسیر:** پیش‌فرض خطی، آپشن Catmull-Rom. اکستراپولیشن: خیر.
11. **حالت تک‌ناظر:** فقط خط دید، بدون نقطه هدف و ارتفاع.

## ۷. رابط کاربری

- **چیدمان:** نقشه تمام‌صفحه + پنل کناری قابل باز/بسته شدن.
- **پنل کناری:** لیست ناظرها، لیست مشاهدات، پنل لایه‌ها، dropdown انتخاب هدف فعال، دکمه‌ها (افزودن ناظر، هدف جدید، بارگذاری نقشه، بارگذاری DEM، محاسبه، Export، Import، بکاپ، Settings).
- **پنل لایه‌ها:** روشن/خاموش، شفافیت، ترتیب، انتخاب Basemap.
- **پاپ‌آپ ناظر:** نام، مختصات، ارتفاع، دو فیلد زاویه، فیلد اختیاری دقت، دکمه‌های تأیید / ویرایش / حذف / «هدف جدید».
- **نمایش روی نقشه:**
  - ناظر: مثلث آبی پررنگ + نام (ثابت در پیکسل، مستقل از زوم).
  - هدف فعال: نقطه قرمز با هاله پالسی نرم + دایره خطا.
  - مسیر: خط زرد (اختیاری)، فقط داخل یک هدف.
  - خط دید: فقط تا پیدایش تقاطع.
- **Tooltip:**
  - روی ناظر → نام، مختصات، آخرین مشاهده.
  - روی هدف → زمان آخرین محاسبه، مختصات، دایره خطا.
- **جدول مشاهدات:** چپ به راست: زمان (شمسی + ساعت لوکال)، ناظر، زاویه سمت، زاویه ارتفاعی، دقت، مختصات هدف، شعاع خطا، وضعیت. مشاهدات غیرفعال با رنگ خاکستری + برچسب «غیرفعال» + فیلتر نمایش.
- **تم:** Dark، RTL، فونت پیش‌فرض Vazir تیتر ۱۴ (همراه EXE، قابل تغییر).
- **اعداد:** همه لاتین.
- **رنگ‌ها:** کاملاً آزاد با color picker.

## ۹. اعتبارسنجی ورودی

| فیلد | محدوده | رفتار در خطا |
|---|---|---|
| زاویه سمت | ۰ تا ۳۶۰ | خطا، درخواست ورود مجدد |
| زاویه ارتفاعی | -90 تا +90 | خطا |
| مختصات x (DD) | -180 تا +180 | خطا |
| مختصات y (DD) | -90 تا +90 | خطا |
| DMS (دقیقه/ثانیه) | ۰ تا ۶۰، جهت معتبر | خطا |
| ارتفاع | -500 تا +9000 | خطا |

**ورودی مختصات:** توگل DD/DMS در Settings سراسری + یک toggle کوچک کنار فیلد ورودی. ذخیره همیشه به‌صورت Decimal Degrees با ۹ رقم اعشار. نمایش DD با ۶ رقم اعشار، DMS با ثانیه ۲ رقم اعشار. زوایا فقط Decimal Degrees.

## ۱۰. پشته فنی

| بخش | فناوری |
|---|---|
| زبان | Python 3.11+ |
| رابط کاربری | PyQt6 / PySide6 |
| نمایش نقشه | QGraphicsView سفارشی (Canvas GIS) |
| خواندن GeoTIFF / DEM | GDAL + rasterio |
| خواندن ECW | پشتیبانی نمی‌شود — ابزار تبدیل جداگانه GDAL → GeoTIFF |
| محاسبات ژئودزیک | pyproj + geographiclib (روش Karney) |
| Least Squares | numpy + scipy |
| دیتابیس | SQLite + SpatiaLite |
| Excel | openpyxl |
| PDF | reportlab |
| لاگ | logging با RotatingFileHandler (۵ فایل × ۱MB، پیش‌فرض INFO) |
| فونت | Vazir (همراه EXE) |
| تست | pytest |
| بسته‌بندی | PyInstaller → EXE تک‌کلیکی |

**مسیر فایل‌ها:** `%APPDATA%\TargetTracker\` شامل `db.sqlite`، `app.log`، `settings.json`، `fonts/`.

**هیچ وابستگی به QGIS نصب‌شده یا SDK تجاری وجود ندارد.**
