## تصمیمات فنی (Frozen)

این تصمیمات قطعی شده‌اند و بدون توافق با کارفرما تغییر نمی‌کنند.

| مورد | تصمیم |
|---|---|
| زبان | Python 3.11+ |
| رابط کاربری | PyQt6 / PySide6 |
| نمایش نقشه | QGraphicsView سفارشی |
| CRS ذخیره‌سازی | WGS84 (EPSG:4326) |
| CRS محاسبه | Lambert Conformal Conic سفارشی ایران |
| CRS ثانویه | UTM Zone 39N (EPSG:32639) |
| دیتابیس | SQLite + SpatiaLite |
| محاسبات ژئودزیک | pyproj + geographiclib (روش Karney) |
| Least Squares | numpy + scipy |
| Excel | openpyxl |
| PDF | reportlab |
| فونت | Vazir (همراه EXE) |
| تست | pytest |
| بسته‌بندی | PyInstaller → EXE تک‌کلیکی |
| خواندن ECW | پشتیبانی نمی‌شود — ابزار تبدیل جداگانه |
| هدف فعال | یک هدف در هر لحظه |
| گروه‌بندی مشاهدات | هر آپدیت → یک نقطه track جدید |
| اعتبارسنجی زاویه سمت | ۰ تا ۳۶۰ |
| اعتبارسنجی زاویه ارتفاعی | -90 تا +90 |
| فرمت ورودی مختصات | DD یا DMS |
| زبان رابط | فارسی RTL |
| تم | Dark |
| اعداد | لاتین |
| ذخیره‌سازی | %APPDATA%\TargetTracker\ |
